/03 · projeto próprio · em uso diário

Atlas

Ferramenta própria · painel de prospecção por WhatsApp

Ferramenta que uso todos os dias. É um painel que mostra quem chamar agora, ordenando pelos negócios que estão abertos no momento. O roteiro da conversa é customizado para cada negócio, e o painel abre o WhatsApp em um clique e guarda o resultado de cada contato. Tem o catálogo dos sites que já fiz, uma biblioteca de designs e vídeos de demonstração para mandar no WhatsApp. Fiz questão de deixar o visual dele combinando com o do meu portfólio. Começou como uma lista simples e foi crescendo com o meu uso.

  • HTML
  • CSS
  • JavaScript
  • Node.js
  • Chrome (CDP)
  • ffmpeg
Painel
Uma página só, sem framework, que lê e grava os contatos em tempo real no banco de dados do claude.ai.
Roteiro
Os textos de abordagem são montados no navegador com o que sei de cada negócio (ramo, cidade, nota no Google). Cada texto pode ser editado e fica salvo.
Vídeos
Um script grava o site rolando com o Chrome e o ffmpeg, e um servidor em Node abre o Explorer com o vídeo selecionado.
Autoria
Eu decido o que ele faz e uso todo dia. O código foi gerado com o Claude Code.

Como eu trabalho

Programo com IA, no Claude Code, e estudo como tirar mais proveito dela. Meu trabalho é decidir o que construir, acompanhar e entender o código gerado, testar e responder pelo que vai para o ar.

O que eu decido

  • O que o negócio precisa e o que fica de fora.
  • O visual, escolhido pelo tipo de cliente.
  • Os textos, sem inventar dado que o cliente não passou.
  • Quando está bom para mostrar.

O que a IA gera

  • O código: HTML, CSS, JavaScript, o servidor e o banco de dados.
  • A sugestão de tecnologia, com o motivo de cada escolha.
  • Os rascunhos de texto, que eu reviso.

Como é testado

  • Cada página é aberta no celular e no computador antes de ir para o ar.
  • Um script confere erros, arquivos que não carregam e rolagem para o lado.
  • Antes de publicar, confiro que o código não leva senha, chave nem dado de cliente.
  • Depois de publicar, abro o link para confirmar que está no ar.
