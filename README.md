# Portfólio: Alexandre Martins

Site com a minha apresentação profissional, em português e inglês.

**No ar:** https://xandemartinsc.pages.dev/

## O que tem

| Endereço | Conteúdo |
|---|---|
| `/` | Página comercial: sites para pequenos negócios |
| `/carreira/` | Apresentação de carreira em português |
| `/carreira/en/` | Mesma apresentação em inglês |
| `/projetos/<nome>/` | Páginas de projetos: alto-giro, dedetimax, espaco-kiara, mi-au, papel-prosa |

Os currículos em PDF (português e inglês) estão na raiz.

## Como funciona

Site estático: HTML, CSS e JavaScript puros, sem framework e sem build. As regras de segurança e cache ficam em `_headers`. Publicado no Cloudflare Pages.

## Como foi feito

Desenvolvido por mim com apoio do Claude Code. Eu defini o conteúdo, a estrutura e as duas línguas, e revisei o que a IA gerou. Sou iniciante em código escrito à mão; o código é escrito com IA e eu respondo pelo que vai para o ar.
